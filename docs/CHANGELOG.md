# Changelog
## 2.1.0
- `soilProps`: незалежні q і ρs (`SoilOpt`), перевірка ρb (RangeError), θ ≤ пористість, повертає пористість n.
- Замерзання: гладка (C¹) частка льоду, `phaseProps`; прибрано стрибок C_eff на межах інтервалу.
- `solve`: гармонічне усереднення λ (збережено), опція `surface` — потік через поверхневий опір R (не змішується з Діріхле).
- `harmonicError` — автоматична E_max; Vitest (13 тестів); docs/.
- Спільний `phaseProps` використовується в `App.tsx`.
