# QA_CHECKLIST — ручна перевірка перед релізом

Автоматично перевіряються розрахунки, дані, правила й переклади (`npm run check`). Нижче — те, що можна перевірити лише в браузері.

## Збірка
- [ ] `npm install` і `npm run check` завершуються без помилок
- [ ] `npm run preview`: застосунок відкривається, у консолі немає помилок і попереджень
- [ ] (GitHub Pages) відкрити опублікований URL у вкладеній директорії `/<repo>/`; перезавантаження на `#lab/mixing` працює

## Вкладки й навігація
- [ ] Чотири вкладки відкриваються; кнопка «Назад» браузера повертає на попередній розділ
- [ ] Прямі посилання: `#theory/atlas/urea`, `#lab/column`, `#calc/npk`, `#practicum/journal`
- [ ] Стрілки ← → переключають вкладки; Tab/Shift+Tab проходить усі елементи з видимим фокусом
- [ ] «Перейти до змісту» (перший Tab) переносить фокус на основну область

## Мова, тема, збереження
- [ ] UK/EN: немає «сирих» ключів (на кшталт `diag.step1`), формули виглядають коректно
- [ ] Світла/темна тема: шапка (світла — зелена, темна — синя), читабельність карток, графіків, бейджів
- [ ] Перезавантаження: мова, тема, обрані добрива для порівняння, останні параметри калькуляторів і лабораторій відновлено
- [ ] Журнал: після кількох спроб — експорт JSON/CSV, «Очистити» (двоетапно), імпорт того ж JSON не створює дублів

## Адаптивність (360 / 768 / 1280 / 1920 px)
- [ ] Таблиці (порівняння, журнал) прокручуються всередині контейнера, сторінка не «їде» вбік
- [ ] Графіки (розчинність, фосфати) вміщуються; вкладки гортаються горизонтально на вузьких екранах
- [ ] Лабораторія й практикум зручні на смартфоні (кнопки не накладаються)

## Доступність
- [ ] Керування клавіатурою: «Змішувальний стіл» (клік замість перетягування), аудит (позначення фрагментів), радіокнопки й чекбокси практикуму
- [ ] Результати (розрахунки, «Змішати», крок колонки) оголошуються (`aria-live`) — перевірити скрінрідером, якщо є
- [ ] Статуси не передаються лише кольором (іконка/текст); `prefers-reduced-motion` вимикає анімації осаду/газу
- [ ] Контраст тексту в обох темах (інструмент браузера, напр. Lighthouse)

## Контрольні приклади
- [ ] Конвертер: 60 кг/га N із карбаміду (46,2 %) → 129,9 кг/га
- [ ] Конструктор NPK: ціль 8:20:20 / 100 кг (амофос, аміачна селітра, KCl) → 38,46 / 9,84 / 33,33 кг, наповнювач ≈ 18,37 кг; ціль 12:26:30 — немає розв’язку (потрібно ≈ 117,4 кг)
- [ ] «Змішувальний стіл»: NH₄NO₃ + CaO → «Несумісні» + NH₃↑; KCl + K₂SO₄ (сухе) → «Сумісні»; карбамід + NH₄NO₃: сухе — несумісні, розчин — сумісні
- [ ] Розчинність: MKP, вода, 20 г / 100 мл / 20 °C → «насичений»; 60 °C → «ненасичений»
- [ ] Фосфати: pH 7,2 → H₂PO₄⁻ і HPO₄²⁻ по 50 %
- [ ] Колонка (KCl, суглинок, помірні опади): Cl⁻ глибше за K⁺, у стоку з’являється Ca²⁺
- [ ] Детектив: розв’язати кожне з 3 завдань початкового рівня; завдання з амофосом приймає також DAP
