# Припущення та обмеження
Базова модель:
- одновимірна, без горизонтального перенесення тепла;
- не враховує перенесення тепла водою (інфільтрація, капілярний підйом, конвекція);
- не враховує випаровування та конденсацію;
- не враховує зміну властивостей через біологічну активність, структуру, розкладання решток;
- використовує ідеалізовані граничні умови (синусоїдальна температура поверхні, постійна температура на нижній межі);
- замерзання: вся вода замерзає в інтервалі 0…−ΔT (за замовчуванням ΔT = 1 К). Реальний вміст незамерзлої води залежить від потенціалу води та властивостей ґрунту; це допустиме спрощення лише для навчального сценарію;
- C_v — адитивна модель твердої й водної фаз без внеску газової;
- проективне вкриття в поточному UI — умовне зменшення амплітуди A·(1−C), а не фізична модель снігу чи решток (див. CHANGELOG: заплановано граничну умову з опором);
- модель не є інструментом прогнозу температури конкретного поля без калібрування за вимірюваннями.
