# Валідація
Тести: `npm test` (Vitest, `src/physics.test.ts`).

## Порівняння з аналітичним розв'язком
Однорідний ґрунт (α = 0,5 мм²/с, d ≈ 11,7 см), без замерзання, A₀ = 10 °C, T_m = 15 °C, 0–50 см, 6 діб прогону.
E_max = max|T_num − T_analytic|, °C:

| Змінна | Значення | E_max |
|---|---|---|
| dt (при dz = 1 см, глибина 1 м) | 300 с / 150 с / 75 с | 0,039 / 0,028 / 0,023 |
| dz (при dt = 300 с) | 2 см / 1 см / 0,5 см | 0,047 / 0,039 / 0,037 |
| Глибина розрахункового профілю | 0,6 м / 1 м / 2 м | 0,032 / 0,039 / 0,043 |

Висновки: похибка ≈ 0,4 % від A₀ і спадає зі зменшенням dt, dz; поріг тесту 0,06 °C обрано за цими результатами (запас ~50 %). Відмінність результатів для профілів 1 м та 2 м < 0,01 °C, тому нижня межа 1 м достатньо віддалена (e^(−100/11,7) ≈ 2·10⁻⁴). Залишкова похибка при малих dt зумовлена не схемою, а початковим перехідним процесом і нижньою межею.

## Інші перевірки
- Двошаровий профіль (λ = 1 і 2, стаціонар): потік по обидва боки межі збігається з аналітичним до 6-го знака.
- R → 0 відтворює Діріхле (різниця < 10⁻⁴ °C).
- Енергобаланс (сталі властивості, потік через поверхню): нев'язка ≈ 5·10⁻¹⁰ Дж/м².
- C_eff неперервна: приріст за 0,001 К ≤ 5·10⁵ Дж/(м³·К) (скінченна друга похідна), без стрибків.
- Не перевірено: енергобаланс при замерзанні (коефіцієнти беруться з попереднього кроку, схема не є строго консервативною); збіжність за ΔT інтервалу замерзання.
