# Математична модель

## 1. Рівняння теплоперенесення (1D, z вниз)
C_eff(T)·∂T/∂t = ∂/∂z (λ(T)·∂T/∂z),  C_eff — об'ємна теплоємність, Дж/(м³·К); λ — Вт/(м·К).

## 2. Пористість
n = 1 − ρb/ρs. ρb — щільність складення (кг/м³), ρs — щільність твердої фази (за замовчуванням 2650 кг/м³; параметр `RHO_S`/`SoilOpt.rs`). Діапазон ρb: 1000–1800 кг/м³. Вологість θ (м³/м³) обмежується: θ ≤ 0,99·n.

## 3. Теплопровідність (Johansen, 1975)
λ = (λ_sat − λ_dry)·Ke + λ_dry
- λ_s = λ_q^q · λ_o^(1−q), λ_q = 7,7; λ_o = 2,0 Вт/(м·К); q — частка кварцу (0–1), **задається незалежно від класу**;
- λ_dry = (0,135ρb + 64,7)/(2700 − 0,947ρb);
- λ_sat = λ_s^(1−n)·λ_w^n, λ_w = 0,57 (вода), 2,2 (лід);
- Sr = θ/n; Ke = 0,7·lg Sr + 1 (грубі, Sr ≥ 0,05) або lg Sr + 1 (дрібні, Sr ≥ 0,1), інакше 0; для мерзлого ґрунту Ke = Sr.
Клас (пісок/суглинок/глина) задає лише вибір кривої Ke та типові q і ρb.

## 4. Теплоємність і α
C_v = (1−n)·C_s + θ·C_w, C_s = 2,0·10⁶, C_w = 4,18·10⁶ (лід 1,93·10⁶) Дж/(м³·К). Повітря в порах не враховано (внесок ≈ 10³ Дж/(м³·К), <0,1 %).
α = λ/C_v (м²/с).

## 5. Гармонічні коливання та глибина проникнення
T(z,t) = T_m + A₀·e^(−z/d)·cos(ω(t − t_max) − z/d), d = √(2α/ω) = √(αP/π), ω = 2π/P.
P = 86400 с (доба; максимум на поверхні о 14:00) або 365 діб (рік; максимум на 200-й день).

## 6. Замерзання (метод ефективної теплоємності)
Частка льоду f_i(T) = s(x), x = clamp(−T/ΔT, 0, 1), s(x) = 3x² − 2x³ (гладка, s′ = 0 на межах інтервалу).
C_eff = (1−f_i)·C_unfrozen + f_i·C_frozen + L_v·θ·6x(1−x)/ΔT; L_v = 3,34·10⁸ Дж/м³ води; ΔT = 1 К (параметр).
λ = (1−f_i)·λ_unfrozen + f_i·λ_frozen. Функція неперервна; стрибків C_eff на межах інтервалу немає.

## 7. Чисельний метод
Скінченні об'єми, крок dz (добовий режим 1 см, 0–100 см; річний 5 см, 0–400 см), повністю неявна схема (Euler назад), задача на кожному кроці розв'язується алгоритмом Томаса. λ на гранях — гармонічне середнє λ_{i+½} = 2λ_iλ_{i+1}/(λ_i+λ_{i+1}); λ і C_eff беруться з попереднього кроку.
Двошаровий профіль: вузол i належить шару 1, якщо i < b. Межа лежить на грані комірок, тобто на глибині (b−½)·dz (відхилення ≤ 0,5 dz; для dz = 1 см ≤ 0,5 см). Контактний опір = 0.

## 8. Граничні та початкові умови
- Поверхня (режим «ідеалізована температура»): Діріхле T(0,t) = T_m + A₀cos(ω(t − t_max)).
- Поверхня (режим «поверхневий опір», підготовлено в `solve`): C₀(dz/2)∂T₀/∂t = λ_{½}(T₁−T₀)/dz + (T_air − T₀)/R, R = 1/h_c + Σh_i/λ_i. R → 0 відтворює Діріхле. Режими не змішуються.
- Низ: Діріхле T_b = T_m (достатньо віддалений: вплив глибини ≤ 0,01 °C, див. VALIDATION.md).
- Початок: T = T_m; попередній прогін: 6 діб (доба) або 3 роки (рік); результат — останній цикл.

## 9. Одиниці та діапазони
T °C; z м (UI: см); λ Вт/(м·К); C_v Дж/(м³·К); α м²/с (UI: мм²/с); ρb 1000–1800 кг/м³; θ 0–n; q 0–1; R м²·К/Вт.
